# Prisma 1.0.2

O símbolo de estrela do logo agora é simétrico e está centralizado. O subtítulo foi removido. O jogo mantém os modos Clássico e Zen e as melhorias de jogabilidade da versão 1.0.1.

Esta versão inclui avisos de autoria e os termos de licença: o código está sob GPL-3.0-only e as cinco imagens listadas em `LICENSE-ART.md` estão sob CC BY-SA 4.0. O APK inclui ambos os arquivos de licença.

**Instalação:** baixe `Prisma-Android.apk` e abra no Android 8 ou mais recente. O APK é assinado com uma chave de desenvolvimento temporária criada pelo GitHub Actions. Se houver uma versão anterior instalada com outra chave, é necessário desinstalá-la antes de instalar a 1.0.2, o que apaga as partidas salvas no aplicativo. As partidas da versão web ficam separadas.
