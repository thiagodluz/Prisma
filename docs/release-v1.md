# Prisma 1.0

O tabuleiro é embaralhado automaticamente quando você sobe de nível, tanto no Clássico quanto no Zen. As mesmas 64 pedras mudam de posição: cores, especiais e pontos são preservados. O resultado tem ao menos uma jogada válida e não começa com combinações já formadas. O embaralhamento manual continua disponível no Zen e usa as mesmas regras.

As metas foram mantidas após simular partidas: 1.800 pontos para passar do nível 1, mais 350 pontos a cada nível, até o limite de 5.300 por nível. As novas pedras continuam surgindo com chances iguais e independentes entre as sete cores, permitindo cascatas.

Inclui os recursos das betas: dois modos, escolha entre os visuais Anterior e Novo, especiais Pulso, Raio e Espectro, pontuação e recordes salvos, som configurável, vibração opcional e jogo offline.

**Instalação:** baixe `Prisma-Android.apk` e abra no Android 8 ou mais recente. Esta compilação distribuída pelo GitHub Actions ainda usa uma chave de desenvolvimento temporária, diferente das betas. Para instalar sobre uma beta, é necessário desinstalá-la primeiro; isso apaga as partidas e preferências salvas no aplicativo. A versão web guarda seu progresso separadamente.
