# Prisma para Android — beta 2

Esta beta corrige o cabeçalho que ficava atrás dos ícones de bateria e notificações em aparelhos com Android recente. A área do jogo agora respeita a barra de status, a barra de navegação e os recortes da tela. Mantém os modos Zen e Clássico, pedras especiais, os dois visuais, controles de som e recursos incluídos no APK para jogar offline.

**Instalação:** baixe `Prisma-Android.apk` nesta página e abra o arquivo no Android 8 ou mais recente. Se solicitado, autorize o aplicativo usado para abrir o download a instalar APKs. Esta versão ainda não está na Play Store.

**Antes de atualizar a beta 1:** o APK tem assinatura de desenvolvimento gerada para esta compilação. O Android provavelmente exigirá a desinstalação da beta 1 antes de instalar a beta 2; isso apaga as partidas e preferências salvas no aplicativo. As partidas da versão web não são transferidas automaticamente para o APK. A posição do cabeçalho ainda precisa ser confirmada em um aparelho físico após esta correção.
