# Prisma para Android — beta 1

Primeiro APK de teste do Prisma. Inclui os modos Zen e Clássico, as pedras especiais, os dois visuais e os controles de som. Todos os recursos do jogo estão dentro do aplicativo para uso sem internet. Partidas, recordes e preferências são salvos no aparelho, e o áudio é pausado quando o aplicativo sai de foco.

**Instalação:** baixe `Prisma-Android.apk` nesta página e abra o arquivo no Android 8 ou mais recente. Se solicitado, autorize o aplicativo usado para abrir o download a instalar APKs. Esta versão ainda não está na Play Store.

**Limitações desta beta:** o APK tem assinatura de desenvolvimento, gerada para esta compilação. Uma compilação futura com outra assinatura poderá exigir a desinstalação desta versão, o que apagaria os dados salvos no aplicativo. As partidas da versão web também não são transferidas automaticamente para o APK. Ainda faltam testes de som, retomada e consumo de bateria em aparelhos Android reais.
