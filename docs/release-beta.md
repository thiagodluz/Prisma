# Prisma para Android — beta 3

Esta beta remove o efeito elástico ao arrastar a página fora do tabuleiro no aplicativo Android, sem bloquear a rolagem normal. Os pontos ganhos aparecem imediatamente junto ao progresso, fora do tabuleiro, enquanto as pedras terminam de animar. No visual Novo, as pedras ficaram um pouco maiores dentro das casas, com as correções de alinhamento preservadas. O visual Anterior mantém seu tamanho.

Mantém os modos Zen e Clássico, pedras especiais, as configurações de som e os recursos incluídos no APK para jogar offline.

**Instalação:** baixe `Prisma-Android.apk` nesta página e abra o arquivo no Android 8 ou mais recente. Se solicitado, autorize o aplicativo usado para abrir o download a instalar APKs. Esta versão ainda não está na Play Store.

**Antes de atualizar uma beta anterior:** cada APK foi assinado com uma chave temporária de desenvolvimento. Talvez seja necessário desinstalar a beta anterior antes de instalar esta; isso apaga as partidas e preferências salvas no aplicativo. As partidas da versão web não são transferidas automaticamente para o APK. O comportamento em aparelhos físicos ainda precisa de confirmação após esta compilação.
