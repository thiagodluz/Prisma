# Prisma 1.0.4

Esta versão melhora a preparação das próximas atualizações. O aplicativo Android agora calcula o código interno de versão automaticamente, evitando publicar um APK que o sistema trate como versão anterior. No navegador, o cache passa a acompanhar alterações dos arquivos do jogo; a compilação verifica se o número da versão foi aumentado quando esses arquivos mudam.

A regra atual do Espectro ativado por cascata foi esclarecida na documentação. A jogabilidade, a pontuação e o visual das pedras não mudaram nesta versão.

**Atualização no Android:** se você já instalou a 1.0.3, pode instalar a 1.0.4 sobre ela sem desinstalar nem apagar as partidas, pois as duas usam a mesma chave permanente. Os APKs 1.0.2 e anteriores usam outra assinatura: para passar deles à 1.0.4, é preciso desinstalar o aplicativo antigo, o que apaga partidas e preferências locais. As partidas do navegador são separadas.

Baixe `Prisma-Android.apk` nos arquivos desta versão. Requer Android 8 ou mais recente. A instalação e o comportamento em aparelhos físicos ainda precisam de validação.
