# Prisma 1.4.1 — Sound Revolution

## Correções

- Os sete áudios agora são servidos pelos arquivos locais do APK, com MIME correto; o WebView permite retomar gravações já ativadas ao voltar ao jogo.
- Apenas Magic Puzzle, Cozy Puzzle e Space City ficam no seletor de música.
- Apenas Riacho, Chuva, Floresta e Floresta após chuva ficam no seletor de ambiente.
- As músicas sintetizadas e ambiências antigas foram removidas. Preferências antigas migram para Cozy Puzzle e Chuva, preservando os controles de volume e a opção ligado/desligado.
- O navegador atualiza a página aberta ao ativar um cache novo, com a partida preservada pelo salvamento existente.
- Erros de reprodução aparecem no painel Zen, com tentativa de novo no próximo toque.

Os efeitos de jogada, clique, explosão e vitória continuam como aprovados anteriormente.

Web, HTML offline e APK usam a mesma fonte 1.4.1. Os áudios continuam incluídos para uso offline.

O HTML independente gerado é anexado a este release junto do APK. Os arquivos de áudio usados no build são verificados por SHA-256.
