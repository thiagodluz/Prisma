# Prisma 1.0.3

Esta atualização melhora a recuperação de partidas salvas, inclusive quando os dados de um modo estão corrompidos. O tabuleiro agora permite navegar pelas pedras com as setas do teclado e mantém o foco após as jogadas. Também foram corrigidos o tempo de exibição das dicas e gravações desnecessárias de recordes.

O APK Android é assinado com uma chave permanente, guardada para as próximas atualizações. A compilação inclui os recursos do jogo para funcionar sem internet.

**Atenção antes de instalar:** os APKs 1.0.2 e anteriores tinham outra assinatura. Se você instalou uma dessas versões, será necessário desinstalá-la antes de instalar a 1.0.3. A desinstalação apaga partidas e preferências guardadas no aplicativo Android. As partidas do navegador ficam separadas.

Baixe `Prisma-Android.apk` nos arquivos desta versão. Requer Android 8 ou mais recente. A instalação e o comportamento em aparelhos físicos ainda precisam de validação.
